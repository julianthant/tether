# Tether project instructions

Read [docs/LEARNING_GUIDE.md](docs/LEARNING_GUIDE.md) before teaching, reviewing,
planning, or changing this project. It defines the user's learning goals and the
guidance-only working agreement.

The user writes the application and tests. Provide implementation code or make
implementation changes only when explicitly requested for that specific task.
An explicit request for setup or documentation authorizes that setup or
documentation work, not implementing the harness. Explain design choices and
test scenarios before implementation. Current instructions from the user take
precedence over this guide.
